# 低碳校园资源循环流转桌面系统 —— 数据库设计

数据库：SQLite。初始化脚本见 [sql/schema.sql](../sql/schema.sql)，程序侧由
`com.campus.recycle.db.DatabaseInitializer` 自动建表与播种。

## 1. E-R 关系概览

```
user 1 ──── n item n ──── 1 category
  │              │
  │ n            │ 1
favorite ── n ────┘
  │
  │ n
flow_record 1 ──── n review
```

- 一个用户可发布多个物品；一个物品属于一个分类。
- 一个用户可收藏多个物品（`favorite` 关联表，`UNIQUE(user_id, item_id)`）。
- 一次流转（`flow_record`）关联一件物品、买/卖双方，可产生多条互评（`review`）。

## 2. 表结构

### 2.1 user（用户）
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK, AUTOINCREMENT | 主键 |
| username | TEXT | NOT NULL, UNIQUE | 用户名 |
| password_hash | TEXT | NOT NULL | 密码哈希（SHA-256） |
| salt | TEXT | NOT NULL | 随机盐 |
| role | TEXT | NOT NULL, CHECK(STUDENT/ADMIN) | 角色 |
| credit_score | INTEGER | NOT NULL, DEFAULT 100 | 信用分 |
| nickname | TEXT | NULL | 昵称 |
| email | TEXT | NULL | 邮箱 |
| created_at | TEXT | NOT NULL, DEFAULT now | 创建时间 |

### 2.2 category（分类）
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK, AUTOINCREMENT | 主键 |
| name | TEXT | NOT NULL, UNIQUE | 分类名 |
| description | TEXT | NULL | 描述 |

### 2.3 item（闲置物品）
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK, AUTOINCREMENT | 主键 |
| seller_id | INTEGER | FK → user.id, NOT NULL | 发布者 |
| category_id | INTEGER | FK → category.id, NOT NULL | 分类 |
| name | TEXT | NOT NULL | 名称 |
| description | TEXT | NULL | 描述 |
| price | REAL | NOT NULL, DEFAULT 0 | 期望价格 |
| status | TEXT | NOT NULL, CHECK(AVAILABLE/RESERVED/SOLD/REMOVED) | 状态 |
| tags | TEXT | NULL | 逗号分隔标签 |
| created_at / updated_at | TEXT | NOT NULL, DEFAULT now | 时间戳 |

### 2.4 favorite（收藏）
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK | 主键 |
| user_id | INTEGER | FK → user.id, NOT NULL | 收藏者 |
| item_id | INTEGER | FK → item.id, NOT NULL | 被收藏物品 |
| created_at | TEXT | NOT NULL, DEFAULT now | 时间 |
| — | — | UNIQUE(user_id, item_id) | 防重复收藏 |

### 2.5 flow_record（流转记录）
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK | 主键 |
| item_id | INTEGER | FK → item.id, NOT NULL | 物品 |
| buyer_id | INTEGER | FK → user.id, NOT NULL | 买家 |
| seller_id | INTEGER | FK → user.id, NOT NULL | 卖家 |
| status | TEXT | NOT NULL, CHECK(PENDING/COMPLETED/CANCELLED) | 状态 |
| created_at / completed_at | TEXT | — | 时间 |

### 2.6 review（评价）
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK | 主键 |
| flow_record_id | INTEGER | FK → flow_record.id, NOT NULL | 关联流转 |
| reviewer_id | INTEGER | FK → user.id, NOT NULL | 评价人 |
| reviewee_id | INTEGER | FK → user.id, NOT NULL | 被评价人 |
| rating | INTEGER | NOT NULL, CHECK(1..5) | 评分 |
| comment | TEXT | NULL | 评语 |
| created_at | TEXT | NOT NULL, DEFAULT now | 时间 |

## 3. 索引

| 索引 | 字段 | 用途 |
| --- | --- | --- |
| idx_item_category | item(category_id) | 按分类检索 |
| idx_item_seller | item(seller_id) | 「我的发布」列表 |
| idx_item_status | item(status) | 按状态过滤 |

## 4. 关键设计说明

- **外键约束开启**：连接建立时执行 `PRAGMA foreign_keys = ON`，保证引用完整性。
- **软删除**：物品下架仅将 `status` 置 `REMOVED`，保留历史记录与统计口径。
- **密码安全**：`password_hash` + `salt` 分离存储，支持重新加盐（改密）。
- **时间戳**：统一使用 `datetime('now','localtime')`，由数据库生成，避免客户端时钟差异。
