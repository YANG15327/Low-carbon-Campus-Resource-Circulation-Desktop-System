# 低碳校园资源循环流转桌面系统 —— 需求规格说明书

| 项目 | 内容 |
| --- | --- |
| 项目名称 | 低碳校园资源循环流转桌面系统 |
| 开发语言 | Java 17（Swing GUI） |
| 数据库 | SQLite（JDBC） |
| 构建工具 | Maven |
| 开发周期 | 8 周（迭代 1–4，每 2 周一个迭代） |
| 小组规模 | 3 人 |

---

## 1. 项目概述

当前高校校园存在大量闲置教材、数码配件、文体用品、生活物资，二手流转信息零散，
缺少轻量化的本地桌面管理系统。本系统面向高校校园，实现闲置物品发布、分类检索、
供需匹配、交易流转、信用评价、数据统计的完整业务闭环，并支持管理员后台管理，
可打包为可独立运行的 Jar 交付部署。

## 2. 用户角色

| 角色 | 说明 | 核心权限 |
| --- | --- | --- |
| 普通学生用户 | 校园内发布/交易闲置物品的主体 | 注册登录、发布/修改/下架物品、检索收藏、发起意向、互评 |
| 系统管理员 | 平台运营维护者 | 用户管理、违规物品下架、类别维护、查看全平台统计 |

## 3. 功能需求

### 3.1 用户账号模块（迭代 2 已实现）
- 注册：用户名、密码、昵称、邮箱；**密码加密存储（SHA-256 + 随机盐）**，绝不明文入库。
- 登录：用户名 + 密码校验。
- 角色区分：`STUDENT` / `ADMIN`。
- 输入合法性校验（防御性编程）：用户名 3–20 位字母数字下划线；密码 6–32 位且含字母与数字。
- 重复用户名检测、错误提示。

### 3.2 闲置物品发布管理（迭代 2 已实现）
- 发布物品：名称、分类、描述、期望交换/售卖价格、状态、标签。
- 修改自己发布的物品；下架自己发布的物品（软删除，状态置 `REMOVED`）。
- 权限控制：仅发布者本人可修改/下架（管理员后台在迭代 3 扩展）。

### 3.3 物品检索与筛选（迭代 2 已实现）
- 按分类、关键词（名称/描述/标签模糊匹配）、价格区间、状态筛选。
- 列表展示；支持收藏（收藏表已建，收藏功能迭代 3 实现）。

### 3.4 供需沟通与流转记录（迭代 3）
- 发起意向沟通，生成流转记录；记录物品成交/交换状态；历史记录持久化。

### 3.5 用户评价模块（迭代 3）
- 流转完成后双方互相评价，维护用户信用分数（初始 100）。

### 3.6 数据统计功能（迭代 3）
- 统计各类物品流转数量、低碳减排估算；生成报表；导出 CSV。

### 3.7 管理员后台（迭代 3）
- 用户管理、违规物品下架、类别维护、全平台流转统计。

### 3.8 GUI 图形界面（迭代 3）
- 基于 Swing/WindowBuilder 的事件驱动 GUI：菜单、弹窗、表格。

### 3.9 拓展加分功能（选做，迭代 4）
- 本地数据备份恢复、操作日志、图片本地存储、智能推荐。

## 4. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 可维护性 | 分层架构、模块解耦、接口分离关注点 |
| 可扩展性 | DAO 模式 + 检索条件对象 + 面向接口，便于新增筛选维度 |
| 健壮性 | 防御性编程、输入校验、统一业务异常体系 |
| 安全性 | 密码加盐哈希存储、常数时间比较 |
| 可追溯性 | 关键操作日志（slf4j） |
| 可测试性 | 核心业务模块 JUnit 单元测试覆盖 |

## 5. 约束与假设

1. 桌面单机应用，SQLite 单连接即可满足并发需求（校园内小规模使用）。
2. 标签采用逗号分隔字符串存储（标签内不允许出现逗号），交换归一化标签表为迭代 4 可选项。
3. 价格为非负数值，支持 0 元（纯交换）场景。
